# RFID-Based Healthcare System

## 📌 Overview
This project focuses on improving patient identification and healthcare monitoring using RFID technology.

## 🚀 Objective
To reduce manual errors in hospitals and improve efficiency using automated identification.

## ⚙️ Working
- Each patient has an RFID tag
- RFID reader scans the tag
- Data is processed using microcontroller
- Patient details are displayed
